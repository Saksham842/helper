# Plan 11-01: Viewport Clipping Fixes, Scroll Reliability, Ctrl+Shift+X Clear Hotkey & Modern Shortcuts UI

## Objective
Fix button viewport clipping so copy buttons never go out of the window; ensure vertical scrolling reliably responds to both `Ctrl+Up/Down` and `PageUp/PageDown`; add global `Ctrl+Shift+X` shortcut to clear the chat without touching the mouse; and overhaul the shortcuts UI into a modern, compact glass modal with keycap badges.

## Context & User Feedback
- Feedback: *"copy button i sgoing out of window ... scroll doen shortcut is not wokring ... update ui of shortcuts ... also there should be shortcut to clear chat"*

## Key Implementation Steps

### 1. Fix Button Viewport Clipping
- In [markdownRenderer.tsx](file:///c:/Users/acer/Desktop/parakeet%20ai/apps/desktop/src/renderer/src/lib/markdownRenderer.tsx):
  - In `<CodeBlock>`, ensure the container has `width: '100%'`, `maxWidth: '100%'`, `boxSizing: 'border-box'`, `overflow: 'hidden'`.
  - In the code block header, ensure the Copy button has `flexShrink: 0`, adequate right margin (`marginRight: '4px'`), and clean alignment so it is never pushed outside the viewport.
- In [LiveCopilotFeed.tsx](file:///c:/Users/acer/Desktop/parakeet%20ai/apps/desktop/src/renderer/src/components/LiveCopilotFeed.tsx):
  - Add `boxSizing: 'border-box'`, `maxWidth: '100%'`, and right padding to all stream headers.
  - Ensure the minimal controls bar wraps cleanly on narrow HUD windows without pushing action buttons off-screen.

### 2. Bulletproof Vertical Scrolling
- In [shortcuts.ts](file:///c:/Users/acer/Desktop/parakeet%20ai/apps/desktop/src/main/shortcuts.ts):
  - Keep `CommandOrControl+Up` / `Down` and add `PageUp` / `PageDown` as aliases to avoid hotkey collisions with foreground editors.
- In [HUDOverlay.tsx](file:///c:/Users/acer/Desktop/parakeet%20ai/apps/desktop/src/renderer/src/components/HUDOverlay.tsx):
  - In the hotkey listener for `scroll_down` and `scroll_up`, scroll both `scrollContainerRef.current` and `window` with fallback direct `scrollTop` increment:
    ```typescript

      scrollContainerRef.current.scrollBy({ top: 160, behavior: 'smooth' });
      scrollContainerRef.current.scrollTop += 160;
    }
    window.scrollBy({ top: 160, behavior: 'smooth' });
    ```
