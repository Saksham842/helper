# Plan 11-02: Ctrl+Shift+F Follow-up Code Bridge & Brute-Force Vision Flow

## Objective
Implement global shortcut `Ctrl+Shift+F` (Follow-up) that immediately bridges the current solved coding problem and solution into Live Copilot conversation context so candidates can seamlessly answer interviewer follow-up questions; and update the Vision Solver prompt structure to present 1. Intuition -> 2. Brute Force Approach & Complexity -> 3. Optimal C++ Code -> 4. Optimal Complexity & Edge Cases.

## Context & User Feedback
- Feedback: *"and in code part .. make sure it gives brute force ... with intution first and then optimal .... and if they ask follow up ..... there should be shortcut that i press and context of my qustion immedatiley goes to copilot .. and i can answer the followup"*

## Key Implementation Steps

### 1. Follow-up Context Bridge (`Ctrl+Shift+F`)
- In [shortcuts.ts](file:///c:/Users/acer/Desktop/parakeet%20ai/apps/desktop/src/main/shortcuts.ts):
  - Register `CommandOrControl+Shift+F` sending action `followup_bridge`.
- In [promptEngine.ts](file:///c:/Users/acer/Desktop/parakeet%20ai/apps/desktop/src/renderer/src/services/promptEngine.ts):
  - Add method `injectSolvedCodeContext(solutionMarkdown: string): void`:
    Formats the solved coding problem, brute force, and optimal C++ solution as a solved question turn in the conversation memory.
- In [VisionSolutionCard.tsx](file:///c:/Users/acer/Desktop/parakeet%20ai/apps/desktop/src/renderer/src/components/VisionSolutionCard.tsx):
  - Add callback or shared context to expose the latest `solutionMarkdown`.
  - Add button in the top bar: "Answer Follow-up (Ctrl+Shift+F)".
- In [App.tsx](file:///c:/Users/acer/Desktop/parakeet%20ai/apps/desktop/src/renderer/src/App.tsx):
  - When `followup_bridge` is triggered:
    1. Extract active solution from `VisionSolutionCard`.
    2. Call `promptEngine.injectSolvedCodeContext(...)`.
    3. Pass this context into `LiveCopilotFeed` so an exchange with interviewer question "Solved Coding Problem Context" and AI solution is displayed in the timeline.
    4. Switch mode to `'live-copilot'`.
    5. Show notification: *"Code Context Linked · Listening for Follow-up..."*.
