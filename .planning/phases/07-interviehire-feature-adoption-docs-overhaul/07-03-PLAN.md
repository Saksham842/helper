# Plan 07-03: Speech Metrics, AI Tone Heuristics & Waiting Room UI

## Objective
Port and enhance IntervieHire's speech analytics, AI tone evaluation, and pre-interview Waiting Room tech check into GhostPilot's web dashboard mock interview simulator.

## Tasks

### 1. Implement Client Speech Metrics Hook
- Create `apps/web/src/hooks/useSpeechMetrics.ts`:
  - Calculate real-time speaking pace (WPM - Words Per Minute).
  - Detect common verbal filler words (`"um"`, `"uh"`, `"like"`, `"you know"`, `"actually"`, `"basically"`, `"sort of"`, `"literally"`).
  - Compute a speaking confidence index (0-100) combining WPM consistency and filler ratio.
  - Return `{ markQuestionEnded, processSpeechChunk, metrics, resetMetrics }`.

### 2. Implement Tone & Delivery Heuristics
- Create `packages/shared/src/evaluation/heuristics.ts`:
  - Delivery style classifier based on delivery tempo, sentence structure, and filler frequency:
    - `Confident & Articulate`
    - `Hesitant / Pausing`
    - `Scripted / Monotone`
    - `Rambling / Run-on`
  - STAR adherence indicator (detects Situation, Task, Action, Result keywords).
  - Actionable improvement tips.

### 3. Build Pre-Interview Waiting Room / Tech Check UI
- Create `apps/web/src/app/dashboard/mock/WaitingRoom.tsx`:
  - Microphone device test with live volume VU meter.
  - Camera preview check (if video enabled).
  - Audio output speaker test.
  - Quick interview walkthrough carousel (tips for clear audio, anti-proctor rules).
  - "Ready to Begin" CTA button that initiates the session.

### 4. Wire Speech Metrics & Waiting Room into Mock Interviewer
- In `apps/web/src/app/dashboard/mock/page.tsx`:
  - Show Waiting Room gate before session starts.
  - Wire `useSpeechMetrics` to live `transcript` updates.
  - Display live metrics (WPM, filler count, pace status) during call.
  - Include speech metrics and tone classification in the final post-call review report.

## Verification Criteria
1. Waiting Room displays audio visualizer test and device readiness check.
2. Speaking into microphone calculates WPM and filler word count accurately.
3. Post-call evaluation report displays delivery style classification and STAR tips.
