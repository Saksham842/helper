# Plan 07-02: Resume Identity Extraction & Question Bank Tagging

## Objective
Port regex-based identity extraction from IntervieHire's `sourcing.ts` into GhostPilot so that candidate name, email, phone number, LinkedIn URL, and experience years are automatically identified upon PDF/DOCX resume upload, displayed cleanly on the Document Vault UI, and stored with document metadata. Expand `packages/shared/src/questionBank.ts` with structured categories, difficulty tiers, and hint guidance.

## Tasks

### 1. Implement Resume Identity & Experience Extraction Utility
- Create `apps/web/src/lib/resumeIdentity.ts`:
  - `extractResumeEmail(text: string): string`
  - `extractResumePhone(text: string): string`
  - `extractResumeLinkedIn(text: string): string`
  - `extractCandidateName(text: string, filename?: string): { name: string; source: 'explicit' | 'header' | 'email' | 'filename' | 'fallback' }`
  - `extractExperienceYears(text: string): { years: number | null; summary: string }`
  - `extractResumeIdentity(text: string, filename?: string): ResumeIdentityResult`
- Pure regex heuristics, fast, robust, and zero AI latency or cost.

### 2. Integrate with Vault Upload API Route
- In `apps/web/src/app/api/vault/upload/route.ts`:
  - After `extractTextFromBuffer(buffer, mimeType, file.name)`, call `extractResumeIdentity(extracted.text, file.name)`.
  - Store `identity` in document metadata JSON or columns if available.
  - Return extracted identity along with the document record in the API response.

### 3. Update Vault Web UI Showcase & Badges
- In `apps/web/src/app/dashboard/vault/page.tsx`:
  - Render an Identity Badge Card below the active resume:
    - Candidate Name, Email, Phone, LinkedIn link, and Experience Years.
    - Status pill indicating source ("Extracted from Resume Header / Contact Info").

### 4. Enhance Question Bank in Shared Package
- In `packages/shared/src/questionBank.ts`:
  - Add tag types: `Behavioural`, `Technical`, `System Design`, `Coding`, `Strategy`, `Communication`.
  - Add difficulty ratings: `1 (Junior/Entry)`, `2 (Mid/Senior)`, `3 (Staff/Lead)`.
  - Add hints and STAR-format guidance for each question.
  - Export typed helper `getQuestionsByCategory(tag?: QuestionTag, difficulty?: number)`.

## Verification Criteria
1. Uploading a resume PDF/DOCX automatically extracts and displays candidate name, email, phone, and experience years.
2. Question bank exports categorized questions with difficulty levels and hints.
3. TypeScript compiles cleanly with zero errors.
