# Plan 07-04: Proctoring Fair-Play Simulator & Self-Serve Data Rights

## Objective
Port IntervieHire's proctoring / fair-play detection mechanics into GhostPilot's mock interview environment so candidates can practice under simulated assessment conditions (tab switch, window blur, keyboard shortcuts, gaze/face direction alerts). Implement a self-serve Data Rights portal (`/dashboard/data-rights`) compliant with DPDP/GDPR allowing candidates to export all transcripts, session notes, and resume data as JSON/ZIP or permanently delete their account.

## Tasks

### 1. Implement Client Proctoring Simulation Hook
- Create `apps/web/src/hooks/useProctoring.ts`:
  - Monitors `visibilitychange` and `window.blur` (tab switch detection).
  - Monitors fullscreen exit if full-screen mode enabled.
  - Monitors restricted keyboard shortcuts (`Ctrl+C`, `Ctrl+V`, `Alt+Tab`).
  - Web camera face orientation / gaze drift warning (using lightweight CSS/canvas optical or posture tracking heuristics).
  - Tracks incident timeline `{ type, timestamp, message }`.
  - Fires discrete unobtrusive warning toasts in the mock interview room.

### 2. Integrate Proctoring Warnings in Mock Interview UI
- In `apps/web/src/app/dashboard/mock/page.tsx`:
  - Allow toggling "Assessment Mode / Strict Proctoring Simulation" on or off.
  - Display live proctoring badge and alert banner when infractions occur.
  - Include fair-play summary (number of tab switches, focus losses) in the post-interview feedback report.

### 3. Build Self-Serve Data Rights Portal
- Create `apps/web/src/app/dashboard/data-rights/page.tsx`:
  - Three self-serve actions:
    1. **Export My Data**: Downloads comprehensive JSON archive of candidate profile, uploaded resume metadata, active directives, session history, transcripts, and AI answers.
    2. **Rectify My Details**: Update stored name, contact information, and preferences.
    3. **Erase My Account**: Irrevocably purges user profile, documents, storage files, sessions, and AI responses.
  - Compliant with DPDP Act 2023 and GDPR Article 17 / Article 20.

### 4. Implement Export & Account Deletion API Routes
- Create `apps/web/src/app/api/user/export-data/route.ts`:
  - Authenticates user via Supabase SSR.
  - Gathers profile, documents, sessions, transcripts, AI responses.
  - Returns formatted JSON attachment with headers `Content-Disposition: attachment; filename="ghostpilot_user_data.json"`.
- Create `apps/web/src/app/api/user/account/route.ts`:
  - Authenticates user via Supabase SSR.
  - Cascades deletion across storage files and database records.
  - Signs out user session.

## Verification Criteria
1. Mock interview room detects tab switch and shows proctor warning toast when toggled on.
2. Clicking "Export My Data" on `/dashboard/data-rights` downloads user JSON archive.
3. TypeScript builds cleanly across the monorepo with zero errors.
