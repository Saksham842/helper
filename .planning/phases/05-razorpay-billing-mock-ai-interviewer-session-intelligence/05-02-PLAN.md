# Plan 05-02: Replace Deepgram with Local Offline Whisper STT & Remove Billing/Credits

## Objective
Pivot the application architecture to a 100% free, unlimited, and offline model by:
1. Completely eliminating all Razorpay dependencies, billing scripts, and credit balance paywalls across `apps/web` and `apps/desktop`, making all sessions and AI features 100% free and unlimited.
2. Replacing the Phase 3 Deepgram Nova-2 cloud WebSocket client in `apps/desktop` with a 100% free, local offline Speech-to-Text engine powered by `@huggingface/transformers` (ONNX Runtime Web with quantized `onnx-community/whisper-base.en`) and a rolling VAD chunker.
3. Feeding the existing dual-channel 16,000 Hz Linear16 PCM streams (`Channel 0 = [Interviewer]`, `Channel 1 = [Candidate]`) directly into the local Whisper transcriber so downstream `QuestionDetector` (Phase 4) and `AIAnswerEngine` receive the identical `TranscriptMessage` events with zero API keys required.
4. Purging `DEEPGRAM_API_KEY` and `RAZORPAY_*` from Zod environment variable schemas.
5. Updating test suites with a new `local-whisper-stt.test.cjs` validating local transcription without external API keys.

## Requirements Covered
- **STT-FREE**: 100% free offline local speech-to-text with dual-channel speaker diarization via `@huggingface/transformers`.
- **BILL-FREE**: 100% free and unlimited access; zero Razorpay dependencies, zero paywalls.

### 2. Implement Local Voice Activity Detector (VAD) & Audio Chunking
- Create `apps/desktop/src/renderer/src/services/vadChunker.ts`:
  - `VADChunker`: Listens to incoming 16kHz PCM audio buffers from `AudioMultiplexer`.
  - Maintains separate circular/rolling audio buffers for **Channel 0 (Interviewer)** and **Channel 1 (Candidate)**.
  - Calculates RMS energy on each channel frame:
    - `SPEECH_THRESHOLD = 0.015`
    - `SILENCE_FRAMES_LIMIT = 20` (~600ms of consecutive silence marks speech pause).
    - `MAX_UTTERANCE_DURATION = 15000` (max 15s per chunk).
  - When a complete speech utterance is delimited on either channel, extracts the channel's audio as a `Float32Array` resampled/normalized for Whisper (16kHz mono).
  - Emits `{ channel: 0 | 1, audioData: Float32Array, timestamp: number }`.

### 3. Implement Local Offline Whisper Transcriber Service
- Create `apps/desktop/src/renderer/src/services/localWhisperClient.ts`:
  - Replaces `DeepgramLiveClient` as the primary transcription engine.
  - Loads pipeline using `@huggingface/transformers`:
    ```ts
    import { pipeline } from '@huggingface/transformers';
    this.transcriber = await pipeline('automatic-speech-recognition', 'onnx-community/whisper-base.en', {
      dtype: 'q8', // Quantized 8-bit ONNX model (~40MB)
      device: 'wasm',
    });
    ```
  - Provides fallback caching in IndexedDB / local app data so model downloads once and runs offline forever.
  - Exposes the identical interface:
    - `onTranscript(callback: (msg: TranscriptMessage) => void)`
    - `onStatusChange(callback: (status: ConnectionStatus, message?: string) => void)`
    - `sendAudio(pcmData: ArrayBuffer): void` (splits stereo PCM, feeds VAD, runs Whisper on voice segments).
  - When transcription finishes:
    - Maps `channel 0` -> `speaker: 'interviewer'`.
    - Maps `channel 1` -> `speaker: 'candidate'`.
    - Dispatches `TranscriptMessage`:
      ```ts
      {
        id: crypto.randomUUID(),
        speaker: channel === 0 ? 'interviewer' : 'candidate',
        text: result.text.trim(),
        timestamp: Date.now(),
        isFinal: true,
      }
      ```
    - Immediately forwards message to `questionDetector.handleTranscript(msg)`.
