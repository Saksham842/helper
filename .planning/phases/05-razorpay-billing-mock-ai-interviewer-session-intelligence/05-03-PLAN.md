# Plan 05-03: Free Voice AI Mock Interviewer & Post-Call Analytics with Question Bank

## Objective
Deliver a 100% free, interactive web-based Voice AI Mock Interviewer simulator using browser-native Web Speech APIs (zero external audio API costs) alongside post-call intelligence reporting and a searchable, categorized personal question bank in `apps/web`.

## Requirements Covered
- **WEB-04**: Interactive Voice AI Mock Interviewer simulator with real-time speech responses using browser-native Web Speech API (`SpeechRecognition` & `speechSynthesis`).
- **WEB-05**: Automated post-call meeting analytics (Executive Summary, Strengths, Areas for Improvement, Action Items) and personal Question Bank indexing.

## Dependencies & Packages
- In `apps/web`:
  - Browser-native Web Speech API (`window.SpeechRecognition` / `window.webkitSpeechRecognition` for candidate speech recognition).
  - Browser-native Web Speech Synthesis API (`window.speechSynthesis` for interviewer voice).
  - Claude 3.5 API route for generating interview questions, follow-ups, and post-call feedback reports.
  - `lucide-react` for UI iconography.

## Tasks

### 1. Build Voice AI Mock Interviewer Simulator
- Create `apps/web/src/app/dashboard/mock/page.tsx` and components:
  - **Track Selection**:
    - "System Design & Cloud Architecture"
    - "Frontend & Full-Stack Engineering"
    - "Algorithms, Data Structures & Problem Solving"
    - "Behavioral & Leadership (STAR Method)"
  - **Persona & Difficulty Settings**:
    - Choose interviewer style: Friendly Mentor, Neutral Evaluator, or Demanding Bar Raiser.
    - Difficulty: Junior, Mid-Level, Senior, Staff/Principal.
    - Toggle resume context: Automatically pulls candidate's active resume from Document Vault!
  - **Live Interview Stage**:
    - Visual Voice Orb / Waveform visualizer reacting to audio states (AI Speaking, Candidate Speaking, Thinking).
    - Uses `window.speechSynthesis` to speak questions aloud with natural voice pitch and cadence.
    - Uses `window.SpeechRecognition` / `webkitSpeechRecognition` to transcribe candidate's verbal answers in real time.
    - Real-time transcript history timeline with speaker bubbles.
    - "Next Question", "Request Hint", and "End Interview & Generate Report" controls.
  - **AI Next Question & Feedback Engine**:
    - API route `apps/web/src/app/api/mock/respond/route.ts`:
      - Evaluates candidate's spoken response against previous questions and active resume.
      - Generates the next logical technical question or follow-up probe.
      - Returns text for TTS speech synthesis.

### 2. Implement Post-Session AI Evaluation & Scorecard
- Create evaluation API route `apps/web/src/app/api/mock/evaluate/route.ts`:
  - Sends full interview transcript to Claude 3.5.
  - Computes multi-pillar rubric score (0-100%):
    - Technical Depth & Correctness
    - Communication & Structural Clarity
    - Problem Solving & Adaptability
  - Generates:
    - Executive Summary
    - Strengths & Standout Answers
    - Detailed Question-by-Question Critique
    - Suggested Model Answers & Key References
    - Actionable Homework & Improvement Plan
  - Saves report into `sessions` table (`status: 'completed'`, `metadata: { scorecard, summary, notes }`).

### 3. Build Post-Call Session Notes Page
- Create `apps/web/src/app/dashboard/sessions/[id]/page.tsx`:
  - Displays session header with date, mode (Live Copilot vs Mock Interview), duration, and overall score badge.
  - Interactive tabs:
    - **Overview**: Executive summary, scorecard radar/bar metrics, key takeaways.
    - **Verbatim Transcript**: Searchable transcript with speaker tags (`[Interviewer]` vs `[Candidate]`) and timestamps.
    - **Questions & Feedback**: Breakdown of every question asked, candidate's response, AI evaluation, and recommended answer.
    - **Action Plan**: Prioritized checklist of concepts to study before the real interview.
  - "Export Report (Markdown / PDF)" button.

### 4. Build Filterable Personal Question Bank
- Create `apps/web/src/app/dashboard/questions/page.tsx`:
  - Auto-indexed question bank fed from all completed live copilot calls and mock interview sessions.
  - Features:
    - **Filter by Category**: System Design, Algorithms, React/Frontend, Database/SQL, Behavioral, Concurrency.
    - **Filter by Difficulty**: Easy, Medium, Hard.
    - **Search Bar**: Instant keyword search across questions and answers.
    - **Question Card**:
      - Question statement with company / session badge.
      - Model answer preview with expandable comprehensive explanation.
      - "Practice Again" button to launch instant mock drill on this specific question.
      - "Bookmark / Star" for revision before upcoming interviews.

## Verification Criteria
1. Web Speech API STT and TTS initialize in supported browser (Chrome, Edge, Safari).
2. Mock interview session progresses through questions and generates realistic voice speech.
3. Spoken answers are transcribed live without external API keys.
4. Completing session triggers scorecard generation and saves to `sessions` table.
5. Session detail page displays comprehensive feedback breakdown and verbatim transcript.
6. Question Bank displays questions with category filtering and keyword search.
