# Plan 12-01: Single Page Canvas Unification & Borderless Code Flow

## Objective
Unify the desktop HUD into a single, continuous page by removing the separate Vision view and mode switchers; stream Vision problem solutions directly into the main chatbot timeline; and render code blocks as continuous borderless text with zero nested sub-scrolling so the entire page scrolls as one document, fully visible even on short screens.

## Key Implementation Steps

### 1. Remove Separate Vision View from `App.tsx` & `HUDOverlay.tsx`
- In [App.tsx](file:///c:/Users/acer/Desktop/parakeet%20ai/apps/desktop/src/renderer/src/App.tsx):
  - Remove `activeMode` state and conditional rendering of `VisionSolutionCard`.
  - Directly render `LiveCopilotFeed` inside `HUDOverlay`.
- In [HUDOverlay.tsx](file:///c:/Users/acer/Desktop/parakeet%20ai/apps/desktop/src/renderer/src/components/HUDOverlay.tsx):
  - Remove the mode toggle pills ("Copilot" vs "Vision") from the top bar.
  - Retain the brand icon, live indicator, universal C++ badge, click-through button, opacity %, key config, hotkeys modal toggle, and collapse buttons.

### 2. Stream Vision Problem Solving Directly into `LiveCopilotFeed.tsx`
- In [LiveCopilotFeed.tsx](file:///c:/Users/acer/Desktop/parakeet%20ai/apps/desktop/src/renderer/src/components/LiveCopilotFeed.tsx):
  - When `onSolveScreen` is triggered (or when `ask_ai` hotkey `Ctrl+Shift+H` is pressed):
    1. Append a new exchange to `exchanges`:
       - `interviewerQuestion`: "Captured On-Screen Problem (DSA / LeetCode)"
       - `interviewerTime`: current time
       - `aiAnswer`: ""
       - `isStreamingAI`: true
    2. Call `visionSolverService.captureAndSolve('C++')`.
    3. Stream tokens into the active exchange's `aiAnswer`.
    4. On complete, set `isStreamingAI: false`, update `turnsRef.current`, and call `promptEngine.injectSolvedCodeContext(fullMarkdown)`.
    5. On error, display error cleanly within the stream exchange.

### 3. Borderless, Continuous Code Rendering in `markdownRenderer.tsx`
- In [markdownRenderer.tsx](file:///c:/Users/acer/Desktop/parakeet%20ai/apps/desktop/src/renderer/src/lib/markdownRenderer.tsx):
  - In `<CodeBlock>`:
    - Remove the outer card border (`border: 1px solid rgba(255, 255, 255, 0.1)`), boxed card background (`background: rgba(10, 14, 26, 0.85)`), and header bottom border.
    - Render a sleek, minimal top indicator: a compact tag with language name (`C++`) and inline `Copy` button.
    - Render `<pre>` with `overflowX: 'hidden'`, `overflowY: 'visible'`, `background: 'transparent'`, `border: 'none'`, and natural typography.
    - Ensure zero separate inner scrolling or height constraints so the code block flows continuously as part of the overall page scroll.

### 4. Update Shortcuts & UI Copy
- In [HotkeyCheatsheet.tsx](file:///c:/Users/acer/Desktop/parakeet%20ai/apps/desktop/src/renderer/src/components/HotkeyCheatsheet.tsx):
  - Clarify description for `Ctrl+Shift+H`: "Capture on-screen problem and stream solution directly into chat timeline".
