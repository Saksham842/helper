# Plan 09-01: Layout Overhaul, Header, Responsive Code Wrapping & Disentangled Global Hotkeys

## Objective
Remove the HUD sidebar completely, allocate 100% of window width to active content, implement an ultra-compact single-row top header (34-36px), enforce strict word wrapping with zero horizontal scrollbars, and cleanly separate global hotkeys for scrolling (`Ctrl+Up/Down`) vs. opacity modulation (`Ctrl+Shift+Up/Down`).

## Tasks

### 1. Ultra-Compact Single Row Header & Sidebar Elimination (`HUDOverlay.tsx`)
- In `apps/desktop/src/renderer/src/components/HUDOverlay.tsx`:
  - Dedicate 100% of the window width to active content.
  - Implement a sleek single-row draggable header bar (height 34–36px):
    - GhostPilot logo & branding with compact status pills.
    - **Live Copilot Status Pill**: Active (green dot), Listening (cyan pulse), or Idle (slate).
    - **Vision Mode Indicator Pill**: `Vision [Ctrl+Shift+H]` button.
    - **Opacity Indicator**: Current opacity % (`Ctrl+Shift+↑/↓`).
    - **Click-Through Status Badge**: `Click-Through: ON/OFF` (`Ctrl+Shift+M`).
    - **Language Badge**: Default `C++` badge.
    - Compact API Key trigger & keyboard cheatsheet popover.
  - Ensure mouse interactions on buttons/pills use `WebkitAppRegion: 'no-drag'`.

### 2. Responsive Code & Text Wrapping (Zero Horizontal Scrollbars)
- In `apps/desktop/src/renderer/src/lib/markdownRenderer.tsx`:
  - In `<pre>` block styling:
    - Change `overflowX: 'auto'` to `overflowX: 'hidden'`.
    - Add `whiteSpace: 'pre-wrap'`, `wordBreak: 'break-word'`, and `overflowWrap: 'anywhere'`.
    - Apply `maxWidth: '100%'` and `boxSizing: 'border-box'`.
  - In `<code>` and inline styles, enforce `wordBreak: 'break-word'` and `whiteSpace: 'pre-wrap'`.
- In `HUDOverlay.tsx` and main app containers:
  - Add root styling `overflowX: 'hidden'`, `maxWidth: '100%'` ensuring no horizontal scrollbar can ever appear regardless of window resizing.

### 3. Disentangle Global Hotkeys for Scrolling vs. Opacity (`shortcuts.ts` + `hud.ts`)
- In `apps/desktop/src/main/shortcuts.ts`:
  - Unbind overlapping keys (`CommandOrControl+Shift+Up/Down` was doing both opacity and scrolling).
  - Register **Vertical Content Scrolling**:
    - `CommandOrControl+Up`: Send `hotkey:action` -> `scroll_up` (scrolls active panel UP by 120px).
    - `CommandOrControl+Down`: Send `hotkey:action` -> `scroll_down` (scrolls active panel DOWN by 120px).
  - Register **HUD Window Opacity Adjustment**:
    - `CommandOrControl+Shift+Up`: Call `hudManager.adjustOpacity(+0.10)` (step +10%, clamp between 0.20 and 1.00).
    - `CommandOrControl+Shift+Down`: Call `hudManager.adjustOpacity(-0.10)` (step -10%, clamp between 0.20 and 1.00).
- In `HUDOverlay.tsx`:
  - Handle `scroll_up` and `scroll_down` IPC events on the active scroll container ref (`scrollBy({ top: ±120, behavior: 'smooth' })`).
  - Render a subtle shortcut legend hint in the top header bar or cheatsheet.

## Verification Criteria
1. HUD overlay has no sidebar; 100% width is dedicated to the active view.
2. The top bar is a single row (34–36px) containing all essential status pills and badges (`C++`, opacity %, click-through, vision).
3. Long lines of C++ code or text wrap naturally to the next line; no horizontal scrollbar exists anywhere.
4. Pressing `Ctrl+Up` / `Ctrl+Down` scrolls the active view by 120px without altering opacity.
5. Pressing `Ctrl+Shift+Up` / `Ctrl+Shift+Down` adjusts window opacity in 10% steps without scrolling the view.
