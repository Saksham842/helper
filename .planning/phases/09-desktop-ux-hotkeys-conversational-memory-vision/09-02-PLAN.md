# Plan 09-02: Live Copilot Mode, Color-Coded Sandwich Feed & Rolling Conversational Memory

## Objective
Implement global hotkey `Ctrl+Shift+L` to launch/reset Live Copilot Mode with auto-starting dual audio and Whisper STT, build the color-coded "sandwiched" conversation timeline (`LiveCopilotFeed.tsx`), and maintain rolling multi-turn conversational memory with candidate spoken response injection for follow-up question awareness.

## Tasks

### 1. Global Hotkey for Live Copilot Mode (`Ctrl+Shift+L`)
- In `apps/desktop/src/main/shortcuts.ts`:
  - Register `CommandOrControl+Shift+L`:
    - Send `hotkey:action` -> `toggle_live_copilot`.
- In `apps/desktop/src/renderer/src/App.tsx` and state management:
  - When `toggle_live_copilot` is received:
    - If active view is not `'live-copilot'`, switch view to `'live-copilot'`.
    - If already in `'live-copilot'` mode, reset active conversation timeline to a clean blank state.
    - Ensure dual-channel audio capture (loopback + mic) and local Whisper STT are running (start automatically if idle).
  - Provide a minimal controls header inside Live Copilot:
    - `Pause/Resume Mic`
    - `Solve Screen [Ctrl+Shift+H]`
    - `Clear Context`
    - `Click-Through [Ctrl+Shift+M]`

### 2. Color-Coded "Sandwiched" Conversation Timeline (`LiveCopilotFeed.tsx`)
- Create `apps/desktop/src/renderer/src/components/LiveCopilotFeed.tsx`:
  - Consolidate raw transcript and AI answers into a cohesive, chronological vertical "sandwich" timeline.
  - Structure each conversational exchange as stacked cards:
    1. **Interviewer Question Block (`[Interviewer]`)**:
       - Accent border: Amber/Cyan (`#38bdf8` sky-blue header).
       - Crisp high-contrast text with timestamp.
    2. **AI Suggested Answer Block (`[AI Copilot]`)**:
       - Placed directly beneath the specific interviewer question.
       - Accent border: Emerald/Green (`#34d399` emerald tint).
       - Streams token-by-token from Groq AI Answer Engine.
    3. **Candidate Spoken Response Block (`[You]`)**:
       - Placed directly below the AI suggestion as the user speaks into the microphone.
       - Accent card: Muted Slate/Purple (`#a78bfa` / violet-slate tint).
  - Support auto-scrolling to newest messages with manual scroll lock when scrolled up.

### 3. Rolling Multi-Turn Conversational Memory & Follow-Up Awareness (`promptEngine.ts` & `aiAnswerEngine.ts`)
- In `apps/desktop/src/renderer/src/services/promptEngine.ts`:
  - Define `ConversationTurn`:
    ```ts
    export interface ConversationTurn {
      id: string;
      role: 'interviewer' | 'ai_suggestion' | 'candidate_spoken';
      text: string;
      timestamp: number;
    }
    ```
  - Update `buildSystemPrompt()`:
    - Explicitly instruct the model: "When the interviewer asks a follow-up or counter-question based on what the candidate actually spoke ([You] / Candidate Spoken), reconcile the candidate's exact words with the new probe and provide the strongest, most natural continuation and defense."
  - Update `buildUserPrompt(question: string, history: ConversationTurn[])`:
    - Format prior turns clearly:
      - `[Interviewer]: ...`
      - `[AI Suggested]: ...`
      - `[Candidate Spoken]: ...`
    - Provide rolling context window of up to 10 previous turns.
- In `apps/desktop/src/renderer/src/services/aiAnswerEngine.ts`:
  - Accept `history: ConversationTurn[]` and pass structured multi-turn conversation into the Groq chat payload.

## Verification Criteria
1. Pressing `Ctrl+Shift+L` switches the HUD view to Live Copilot mode and auto-starts audio capture if idle.
2. Pressing `Ctrl+Shift+L` while already on Live Copilot clears conversation turns to a fresh blank screen.
3. Live Copilot renders distinct color-coded cards in sandwich order: `[Interviewer]` (cyan/sky-blue) -> `[AI Copilot]` (emerald green) -> `[You]` (slate/violet).
4. When candidate speaks into mic after an AI suggestion, spoken text is captured in `[You]` card and added to rolling history.
5. Interviewer follow-up questions include `[Candidate Spoken]` in the prompt context to generate context-aware defense answers.
