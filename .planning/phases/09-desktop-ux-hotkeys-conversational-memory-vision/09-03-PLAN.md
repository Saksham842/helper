# Plan 09-03: Instant Vision Solver Switch, Strict Output Ordering, C++ Defaults & Verification

## Objective
Implement instant mode switching to the Question Solving Page on `Ctrl+Shift+H`, enforce strict Groq Vision prompt ordering (Intuition Script -> C++ Code -> Complexity After Code), set C++ as default everywhere, and verify all automated test suites and Windows packaging.

## Tasks

### 1. Instant Vision Solver Switch (`Ctrl+Shift+H`) & State-Preserving Switcher
- In `apps/desktop/src/renderer/src/App.tsx`:
  - Implement a state-preserving view switcher managing active mode: `'live-copilot' | 'vision-solver'`.
  - Both `LiveCopilotFeed` and `VisionSolutionCard` remain mounted in memory with visibility toggled via CSS, preventing stream cancellation, scroll reset, or loss of solved code.
  - When `hotkey:action` -> `ask_ai` (`Ctrl+Shift+H`) is triggered:
    - Automatically switch active view to `'vision-solver'`.
    - Trigger silent screenshot capture and start solving immediately.
    - Keep background audio capture and Whisper STT running uninterrupted.
  - When `Ctrl+Shift+L` is triggered:
    - Switch back to `'live-copilot'` mode instantly without re-rendering or losing the solved code in the Vision tab.

### 2. Strict Top-to-Bottom Groq Vision Output Ordering (`visionSolver.ts`)
- In `apps/desktop/src/renderer/src/services/visionSolver.ts`:
  - Default `targetLanguage` parameter set to `'C++'`.
  - Update Groq Vision system prompt and structure instructions to strictly follow this exact top-to-bottom sequence:
    1. **What to Say Out Loud (First-Person Intuition Script)**:
       - Header: `### What to Say Out Loud`
       - 3–4 natural, conversational bullet points in first-person speech (`"My initial intuition here is to use a monotonic stack because..."`).
    2. **Optimal C++ Solution Code**:
       - Header: `### Solution (C++)`
       - Fenced code block ` ```cpp ` with clean, production-ready, well-commented modern C++20 code (`std::vector`, `std::unordered_map`, STL algorithms).
    3. **Time & Space Complexity Analysis (Placed Strictly AFTER Code)**:
       - Header: `### Complexity & Edge Cases`
       - `Time Complexity: O(...)` with 1-line justification.
       - `Space Complexity: O(...)` with 1-line justification.
       - Key edge cases to mention to the interviewer.
  - In `apps/desktop/src/renderer/src/components/VisionSolutionCard.tsx`:
    - Set default language state to `C++`.
    - Ensure language selector lists `C++` first or selected by default.
