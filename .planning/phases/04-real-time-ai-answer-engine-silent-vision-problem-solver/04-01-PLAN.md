# Plan 04-01: Question Detection Heuristics & Context Assembly Engine

## Objective
Implement intelligent question detection heuristics that identify when the interviewer asks a question and finishes speaking, combined with a dynamic prompt assembly engine that injects candidate resume text, target role context, and custom instructions.

## Requirements Covered
- **AI-01**: Automatic question detection heuristics trigger AI answers when the interviewer stops speaking, complemented by a manual instant hotkey prompt.
- **AI-02**: Candidate resume context, target role description, and custom instructions assembled into interview prompt payloads.

## Tasks
1. Create `apps/desktop/src/renderer/src/services/questionDetector.ts`:
   - Evaluate transcript streams for question patterns: interrogative markers, syntax patterns, question marks.
   - Silence detector: 1200ms debounce after finalized interviewer sentence.
   - Filter false positives: short affirmations ("ok", "yeah", "sounds good", "right").
   - Event emitter: `onQuestionDetected(questionText, fullContext)`.
2. Create `apps/desktop/src/renderer/src/services/promptEngine.ts`:
   - Context store:
     - `resumeText`: string (up to 20,000 characters)
     - `targetRole`: string
     - `customInstructions`: string (STAR format, concise bullet points, etc.)
     - `history`: TranscriptMessage[]
   - Formats optimized system prompt for Claude 3.5 Sonnet / Haiku:
     - Clear persona: Real-time Technical Interview Copilot.
     - Enforces executive scannability: 3-4 bullet points, key metrics, technical keywords bolded.
3. Add unit tests in `apps/desktop/tests/question-detector.test.cjs` validating question detection rules and prompt assembly.

## Verification
- Verify question detection correctly identifies questions while ignoring non-question remarks.
- Verify prompt engine includes candidate resume and custom instructions.
