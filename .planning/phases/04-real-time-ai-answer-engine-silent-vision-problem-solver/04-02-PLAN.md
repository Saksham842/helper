# Plan 04-02: Claude 3.5 Streaming Answer Pipeline & HUD Card Rendering

## Objective
Implement sub-second streaming answers using Anthropic Claude 3.5 API with Server-Sent Events (SSE) streaming and real-time token-by-token card rendering on the floating HUD overlay.

## Requirements Covered
- **AI-01**: Manual instant hotkey prompt (`Ctrl/Cmd + Shift + H` / "Ask AI Now").
- **AI-02**: Streaming answer generation powered by Claude 3.5 Sonnet / Haiku with full candidate resume context.

## Tasks
1. Create `apps/desktop/src/renderer/src/services/aiAnswerEngine.ts`:
   - Anthropic Claude 3.5 streaming API client (`https://api.anthropic.com/v1/messages` with `stream: true`).
   - Supports Claude 3.5 Sonnet (`claude-3-5-sonnet-20241022`) and Claude 3.5 Haiku (`claude-3-5-haiku-20241022`).
   - Handles SSE stream chunks, accumulating markdown text in real-time.
   - Provides abort / cancel mechanism for outdated questions.
2. Build `apps/desktop/src/renderer/src/components/AIAnswerCard.tsx`:
   - Ultra-clean scannable markdown HUD card.
   - High-contrast visual cues: emerald bullet points, highlighted technical keywords.
   - Quick action controls: Copy answer, Regenerate, Expand/Collapse, Dismiss.
3. Integrate `AIAnswerCard` into `HUDOverlay` above or alongside the transcript stream.

## Verification
- Verify streaming answer pipeline accumulates chunks correctly.
- Verify HUD answer card renders tokens smoothly with markdown syntax.
