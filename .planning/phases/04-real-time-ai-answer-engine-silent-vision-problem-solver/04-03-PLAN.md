# Plan 04-03: Silent Desktop Screenshot Capture & Claude 3.5 Vision Problem Solver

## Objective
Implement silent desktop screenshot capture via Electron `desktopCapturer` triggered by global shortcut (`Ctrl/Cmd + Shift + H`), and analyze the captured coding problem (LeetCode, HackerRank, CoderPad) or system architecture using Claude 3.5 Vision to stream code solutions, explanations, and complexity analysis.

## Requirements Covered
- **AI-03**: Silent full-screen capture triggered via global shortcut (`Ctrl/Cmd + Shift + H`) using `desktopCapturer.getSources({ types: ['screen'] })` without OS screenshot UI or clipboard alteration.
- **AI-04**: Claude 3.5 Vision integration analyzes coding screenshots to solve DSA, LeetCode, HackerRank, and system design challenges with step-by-step code, explanation, and time/space complexity.

## Tasks
1. Extend `apps/desktop/src/main/hud.ts` / IPC:
   - IPC handler `screen:capture-silent`: Calls `desktopCapturer.getSources({ types: ['screen'], thumbnailSize: { width: 1920, height: 1080 } })`.
   - Returns base64 encoded image string (data URL) completely in-memory with zero disk persistence and zero clipboard touch.
2. Update `apps/desktop/src/preload/index.ts`:
   - Expose `captureSilentScreenshot(): Promise<string>` on `window.electronAPI`.
3. Create `apps/desktop/src/renderer/src/services/visionSolver.ts`:
   - Claude 3.5 Vision API call passing base64 screenshot image:
     ```json
     {
       "role": "user",
       "content": [
         {
           "type": "image",
           "source": {
             "type": "base64",
             "media_type": "image/jpeg",
             "data": "..."
           }
         },
         {
           "type": "text",
           "text": "Analyze the coding problem on screen and provide: 1) Problem Summary, 2) Optimal Approach (Time & Space Complexity), 3) Complete Production Code Solution with comments."
         }
       ]
     }
     ```
   - Streams solution directly to HUD.
4. Build `apps/desktop/src/renderer/src/components/VisionSolutionCard.tsx`:
   - Syntax-highlighted code block with target language switcher (Python, TypeScript, Java, C++, Go).
   - Time and space complexity badges (e.g. `O(n log n) Time`, `O(1) Space`).
   - Copy solution button with keyboard shortcut.
5. Create automated test harness `apps/desktop/tests/vision-capture.test.cjs` validating silent capture data URL generation and response parsing.

## Verification
- Run test harness verifying silent screenshot capture produces valid base64 image data without OS dialogs.
- Turborepo typecheck and build pass with zero errors.
