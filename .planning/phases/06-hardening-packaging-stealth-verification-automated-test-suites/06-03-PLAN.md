# Plan 06-03: Desktop Installer Packaging & Web Deployment

## Objective
Configure `electron-builder` in `apps/desktop` to produce neutral-branded production installers for Windows (NSIS `.exe`) and macOS (`.dmg`) with hardened Electron fuses and proper macOS audio/screen permissions entitlements. Configure `apps/web` for zero-click Vercel deployment with `/api/health` endpoint and clean `.env.example` files. Generate a comprehensive root `README.md`.

## Requirements Covered
- **STLTH-05**: Neutral executable packaging with `SystemAudioHelper` process branding.
- **QUAL-01**: Production build verification and deployment configuration.

## Dependencies & Packages
- In `apps/desktop` devDependencies:
  - `electron-builder` — production cross-platform installer packaging
  - `@electron/fuses` — programmatic Electron fuse hardening at pack time

## Tasks

### 1. Install electron-builder

Install in `apps/desktop`:
```bash
pnpm --filter @ghostpilot/desktop add -D electron-builder @electron/fuses
```

Add build scripts to `apps/desktop/package.json`:
```json
{
  "scripts": {
    "pack": "vite build && electron-builder --dir",
    "dist": "vite build && electron-builder",
    "dist:win": "vite build && electron-builder --win",
    "dist:mac": "vite build && electron-builder --mac"
  }
}
```

### 2. Create `electron-builder.yml`

Create `apps/desktop/electron-builder.yml`:
```yaml
appId: com.systemaudiosync.helper
productName: SystemAudioHelper
copyright: "Copyright © 2024 SystemAudioHelper"

# Directories
directories:
  output: release
  buildResources: build

# Files to include in ASAR
files:
  - dist/**/*
  - dist-electron/**/*
  - "!node_modules"
  - "!tests"
  - "!src"
  - "!*.ts"
  - "!*.map"

# ASAR packaging (required for OnlyLoadAppFromAsar fuse)
asar: true

# Windows NSIS Installer
win:
  target:
    - target: nsis
      arch:
        - x64
  icon: build/icon.ico
  requestedExecutionLevel: requireAdministrator
  artifactName: "${productName} Setup ${version}.${ext}"

nsis:
  oneClick: true
  perMachine: false
  allowToChangeInstallationDirectory: false
  deleteAppDataOnUninstall: false
  runAfterFinish: false

# macOS DMG
mac:
  target:
    - target: dmg
      arch:
        - x64
        - arm64
  icon: build/icon.icns
  category: public.app-category.productivity
  entitlements: build/entitlements.mac.plist
  entitlementsInherit: build/entitlements.mac.plist
  hardenedRuntime: true
  artifactName: "${productName}-${version}-${arch}.${ext}"

dmg:
  title: "${productName} ${version}"
  background: build/dmg-background.png
  window:
    width: 540
    height: 380

# Electron Fuses (applied via afterPack hook)
afterPack: scripts/apply-fuses.js

# Linux (future — not active in Phase 6)
# linux:
#   target: AppImage
```

### 3. Create macOS Entitlements Plist

Create `apps/desktop/build/entitlements.mac.plist`:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
  <dict>
    <!-- Microphone access for candidate speech capture -->
    <key>com.apple.security.device.audio-input</key>
    <true/>
    <!-- Screen capture for loopback system audio and vision solver screenshots -->
    <key>com.apple.security.device.camera</key>
    <false/>
    <!-- ONNX WASM runtime requires unsigned-executable-memory -->
    <key>com.apple.security.cs.allow-unsigned-executable-memory</key>
    <true/>
    <!-- Electron native addons (node-record-lpcm16 / portaudio) -->
    <key>com.apple.security.cs.disable-library-validation</key>
    <true/>
    <!-- JIT required for ONNX runtime WASM -->
    <key>com.apple.security.cs.allow-jit</key>
    <true/>
  </dict>
</plist>
```

### 4. Create Electron Fuse Hardening Hook

Create `apps/desktop/scripts/apply-fuses.js`:
```js
const { flipFuses, FuseVersion, FuseV1Options } = require('@electron/fuses');
const path = require('path');

exports.default = async function afterPack(context) {
  const ext = context.electronPlatformName === 'win32' ? '.exe' : '';
  const executablePath = path.join(
    context.appOutDir,
    `${context.packager.appInfo.productName}${ext}`
  );

  await flipFuses(executablePath, {
    version: FuseVersion.V1,
    [FuseV1Options.RunAsNode]: false,
    [FuseV1Options.EnableNodeCliInspectArguments]: false,
    [FuseV1Options.OnlyLoadAppFromAsar]: true,
  });

  console.log('[Fuses] Electron security fuses applied:', executablePath);
};
```
