<task type="auto" id="01-02-01">
<title>Create Supabase Core Database Schema Migration & RLS Policies</title>
<instruction>
Create `supabase/migrations/20261024000000_core_schema.sql` defining:
1. `profiles`:
   - `id UUID PRIMARY KEY REFERENCES auth.users ON DELETE CASCADE`
   - `email TEXT NOT NULL`
   - `full_name TEXT`
   - `avatar_url TEXT`
   - `credits_balance INTEGER NOT NULL DEFAULT 50`
   - `plan_tier TEXT NOT NULL DEFAULT 'free'`
   - `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`
   - `updated_at TIMESTAMPTZ NOT NULL DEFAULT now()`
2. `sessions`:
   - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
   - `user_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE`
   - `title TEXT NOT NULL`
   - `mode TEXT NOT NULL CHECK (mode IN ('interview', 'general_call', 'mock'))`
   - `language TEXT NOT NULL DEFAULT 'en'`
   - `custom_instructions TEXT`
   - `status TEXT NOT NULL DEFAULT 'active' CHECK (status IN ('active', 'completed', 'archived'))`
   - `save_transcript BOOLEAN NOT NULL DEFAULT true`
   - `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`
3. `documents`:
   - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
   - `user_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE`
   - `name TEXT NOT NULL`
   - `file_path TEXT NOT NULL`
   - `file_type TEXT NOT NULL CHECK (file_type IN ('pdf', 'docx'))`
   - `extracted_text TEXT`
   - `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`
4. `transcripts`:
   - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
   - `session_id UUID NOT NULL REFERENCES sessions(id) ON DELETE CASCADE`
   - `user_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE`
   - `speaker TEXT NOT NULL CHECK (speaker IN ('interviewer', 'candidate'))`
   - `content TEXT NOT NULL`
   - `timestamp BIGINT NOT NULL`
   - `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`
5. `ai_responses`:
   - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
   - `session_id UUID NOT NULL REFERENCES sessions(id) ON DELETE CASCADE`
   - `user_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE`
   - `question TEXT NOT NULL`
   - `answer TEXT NOT NULL`
   - `response_type TEXT NOT NULL CHECK (response_type IN ('bullet_points', 'full_answer', 'code_solution'))`
   - `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`
6. `credit_transactions`:
   - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
   - `user_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE`
   - `amount INTEGER NOT NULL`
   - `transaction_type TEXT NOT NULL CHECK (transaction_type IN ('credit_purchase', 'session_usage', 'mock_interview_usage'))`
   - `reference_id TEXT`
   - `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`
7. Enable RLS on all tables and create policies ensuring users can only read/write their own records (`auth.uid() = user_id` or `auth.uid() = id`).
8. Add `handle_new_user()` trigger on `auth.users` to automatically create a `profiles` entry upon signup.
</instruction>
<verification>
Verify SQL file contains all 6 tables, triggers, indices, and RLS policies without syntax errors.
</verification>
</task>
