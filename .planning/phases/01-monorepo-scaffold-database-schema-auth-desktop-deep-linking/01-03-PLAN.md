<task type="auto" id="01-03-01">
<title>Register and Implement Custom Protocol Handler in apps/desktop</title>
<instruction>
1. Create `apps/desktop/src/main/protocol.ts`:
   - Register default protocol client `copilot` via `app.setAsDefaultProtocolClient('copilot')`.
   - Implement `handleDeepLinkUrl(url: string)`:
     - Parse URL protocol, pathname (`//auth` or `/auth`), and query parameter `token`.
     - Validate token format and dispatch IPC event `auth:token-received` to mainWindow renderer.
2. In `apps/desktop/src/main/index.ts`:
   - Acquire single instance lock via `app.requestSingleInstanceLock()`.
   - If second instance launched, restore/focus main window and call `handleDeepLinkUrl(commandLine.pop())` (Windows).
   - Listen for `app.on('open-url', (event, url) => { ... })` for macOS deep-link events.
   - On cold start, check `process.argv` on Windows for protocol URLs.
3. In `apps/desktop/src/preload/index.ts`:
   - Expose `window.electronAPI.onAuthTokenReceived((token) => callback(token))`.
4. In `apps/desktop/src/renderer/src/App.tsx` and `AuthStatus.tsx`:
   - Display current desktop status: "Waiting for authentication from web dashboard..." or "Connected as [User Email] - Session Ready".
</instruction>
<verification>
Verify TypeScript compilation and verify protocol registration functions exist in desktop main process.
</verification>
</task>

<task type="auto" id="01-03-02">
<title>Implement Token Generation Route and Launch Button in apps/web</title>
<instruction>
1. Create `apps/web/src/app/api/auth/desktop-token/route.ts`:
   - Protected API route verifying user authentication via Supabase server client.
   - Generates a short-lived desktop handoff token containing user ID, email, and timestamp.
   - Returns `{ token, launchUrl: 'copilot://auth?token=' + token }`.
2. Create `apps/web/src/components/LaunchDesktopButton.tsx`:
   - Client component rendering a prominent "Launch Desktop App" button.
   - On click, fetches token from `/api/auth/desktop-token` and invokes `window.location.href = launchUrl`.
   - Displays friendly feedback if the desktop application opens, with a fallback copy-token button.
3. Integrate `LaunchDesktopButton` into `apps/web/src/app/dashboard/page.tsx`.
</instruction>
<verification>
Verify API route responds with valid token format and component integrates into dashboard without type errors.
</verification>
</task>
