# Plan 13-01: Pure Linear Chatbot Timeline & Viewport Auto-Scroll Clearance

## Objective
Eliminate the multi-section `SandwichExchange` composite structure and replace it with a pure linear chatbot stream (`ChatMessage[]` where Interviewer, AI Solution, You, and AI Evaluation are sequential first-class messages). Add generous bottom clearance (`paddingBottom: 56px`) and multi-trigger auto-scrolling so candidate speech and new answers are never clipped or hidden at the bottom of the HUD.

## Key Implementation Steps

### 1. Refactor Data Model to `ChatMessage` in `LiveCopilotFeed.tsx`
- Replace `SandwichExchange` with:
  ```ts
  export type ChatRole = 'interviewer' | 'ai_solution' | 'candidate' | 'ai_evaluation' | 'vision_solution';

  export interface ChatMessage {
    id: string;
    role: ChatRole;
    text: string;
    timestamp: string;
    isStreaming?: boolean;
    error?: string | null;
  }
  ```
- Store messages as `const [messages, setMessages] = useState<ChatMessage[]>([])`.

### 2. Streamlined Linear Message Rendering (Claude/ChatGPT Style)
- Render each message in a clean, vertical chronological stream on the single continuous canvas:
  - **Interviewer (`role: 'interviewer'`)**:
    - Header: Subtle sky/cyan pill `CALL` or `INTERVIEWER` + timestamp.
    - Body: Crisp white question text.
  - **AI Solution (`role: 'ai_solution'` | `'vision_solution'`)**:
    - Header: Emerald/green pill `AI COPILOT` (or blue `VISION CODE SOLVER`) + spinning indicator if streaming + Copy button.
    - Body: `MarkdownView` with syntax-highlighted continuous code and clear typography.
  - **Candidate (`role: 'candidate'`)**:
    - Header: Purple pill `YOU` + timestamp.
    - Body: Clean lavender text (`#cbd5e1`) displaying what the candidate said aloud into the microphone. No longer tucked at the bottom of a previous card!
  - **AI Evaluation (`role: 'ai_evaluation'`)**:
    - Header: Amber/Gold pill `COACH / EVALUATION` + streaming indicator.
    - Body: Concise feedback, missed edge cases, and "What to say next" guidance.

### 3. Generous Viewport Bottom Clearance & Reliable Auto-Scroll
- In `LiveCopilotFeed.tsx`:
  - Add `paddingBottom: '56px'` to the message list container so the newest message has ample breathing room above the window bottom bezel.
  - Ensure `scrollToBottom()` scrolls the parent `scrollContainerRef` via:
    ```ts
    const scrollToBottom = () => {
      if (messagesEndRef.current) {
        messagesEndRef.current.scrollIntoView({ behavior: 'smooth' });
      }
    };
    ```
  - Trigger `scrollToBottom()` on:
    - `messages` changes
    - Whisper transcript updates (candidate speaking)
    - Groq token streaming updates (`onToken`)

### 4. Remove Compound Divider Borders & Multiple Canvases
- Remove `borderBottom: 1px solid rgba(255,255,255,0.07)` dividers between sandwich chunks.
- Render messages as a single cohesive conversation flow with consistent `gap: '12px'`.
