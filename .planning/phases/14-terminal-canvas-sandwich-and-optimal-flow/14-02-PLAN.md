# Plan 14-02: 5-Tier Coding Solution Sequence Across Live AI & Silent Vision Solver

## Objective
Enforce the strict 5-tier coding solution sequence across both Live AI answers and Silent Vision problem solving: (1) Intuition (What to say) -> (2) Brute Force Approach & Complexity -> (3) Optimal Approach & Concept (explaining strategy & data structures to the interviewer *before* writing code) -> (4) Optimal C++ Code (complete runnable modern C++20) -> (5) Optimal Complexity & Edge Cases. Update parsers, markdown headers, and test harnesses.

## Key Implementation Steps

### 1. Update `promptEngine.ts` for 5-Tier Structure
- In `buildSystemPrompt()`:
  Update the CODING / ALGORITHMS / LEETCODE / DSA instructions to strictly require:
  ```markdown
  ### 1. INTUITION / WHAT TO SAY
  - Immediate punchy 2-3 sentence verbal explanation to say out loud to the interviewer.

  ### 2. BRUTE FORCE APPROACH
  - Describe the naive approach, why it works, and state:
    - Time Complexity: O(...)
    - Space Complexity: O(...)

  ### 3. OPTIMAL APPROACH & CONCEPT
  - Explain the optimal conceptual strategy (which algorithm, data structure, invariant, or technique to use and why it improves upon brute force) to explain to the interviewer BEFORE writing code.

  ### 4. OPTIMAL C++ CODE
  - Complete, clean, runnable modern C++20 code using STL containers (std::vector, std::unordered_map, etc.) with zero omitted lines.

  ### 5. OPTIMAL COMPLEXITY & EDGE CASES
  - Time Complexity: O(...)
  - Space Complexity: O(...)
  - 2-3 critical edge cases to highlight.
  ```

### 2. Update `visionSolver.ts` Prompt & Parser
- In `visionSolver.ts`:
  - Update `VISION_SYSTEM_PROMPT` to enforce the identical 5-tier sequence.
  - Update `parseSolutionResponse()` regex and extraction logic:
    - Extract `intuitionScript` from Tier 1.
    - Extract `bruteForceApproach` and `bruteForceComplexity` from Tier 2.
    - Extract `optimalApproach` from Tier 3.
    - Extract optimal C++ code from Tier 4 code block.
    - Extract optimal `timeComplexity`, `spaceComplexity`, and `edgeCases` from Tier 5.

### 3. Enhance `markdownRenderer.tsx` Section Colors
- In `sectionColor()`:
  - Add color tokens for:
    - `optimal approach`: `#a78bfa` (violet)
    - `brute force`: `#fbbf24` (amber/orange)
    - `intuition`: `#38bdf8` (sky/cyan)
    - `complexity`: `#fb923c` (orange)
    - `code`: `#34d399` (emerald)

### 4. Update Test Suites
- In `apps/desktop/tests/vision-capture.test.cjs`:
  - Update mock vision response and assertions to verify the complete 5-tier sequence:
    Intuition -> Brute Force -> Optimal Approach -> Optimal Code -> Complexity.
- In `apps/desktop/tests/question-detector.test.cjs`:
  - Update assertions for 5-tier prompt rules.

## Verification

- Run `pnpm --filter desktop test` to verify all 5 test suites pass with 5-tier assertions.
- Run `pnpm --filter desktop run pack` to compile and package production binary.
