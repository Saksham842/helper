# Plan 14-01: Terminal-Style Infinite Canvas, Static Block Flow & Sandwich Chat Grouping

## Objective
Transform the Live Copilot feed into an ultra-dense, terminal-style infinite canvas (like an IDE console / terminal buffer) that eliminates bulky card wrappers, flex layout shifts, and wasted vertical space. Group interactions into cohesive sandwich blocks (`[Interviewer Question] -> [Copilot Solution] -> [What You Spoke / Coach]`) with zero inner sub-scrolling and generous bottom clearance so that over 85% of the window is immediately readable code and text.

## Key Implementation Steps

### 1. Ultra-Dense Terminal Styling in `LiveCopilotFeed.tsx`
- Eliminate multi-line avatar badges, colored card backgrounds, and heavy margins.
- Render clean terminal-style line prefixes:
  - `> INTERVIEWER [time]:` (Sky Blue `#38bdf8`, bold, monospace)
  - `> COPILOT [C++]:` (Emerald `#34d399` / Blue `#60a5fa`) with compact `[Copy]` button
  - `> YOU [time]:` (Violet `#a78bfa`, monospace)
  - `> COACH:` (Amber `#fbbf24`, monospace)
- Use crisp monospace font (`ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`), 12px font size, and dense line spacing so multiple sections fit on screen at once.

### 2. Cohesive Sandwich Exchange Data Model
- Structure state into `SandwichTurn`:
  ```ts
  export interface SandwichTurn {
    id: string;
    interviewerQuestion: string;
    interviewerTime: string;
    copilotAnswer: string;
    copilotTime: string;
    isStreamingCopilot: boolean;
    isVision?: boolean;
    candidateSpoken: string;
    candidateTime?: string;
    coachEvaluation?: string;
    isStreamingCoach?: boolean;
    error?: string | null;
  }
  ```
- Each sandwich turn forms a single contiguous block in the terminal canvas:
  1. Prompt / Question on top (`> INTERVIEWER:`)
  2. Complete Solution / Code in the middle (`> COPILOT:`)
  3. Candidate speech and coaching at the bottom (`> YOU:` / `> COACH:`)
- Distinct turns are separated by a subtle 1px dashed line (`borderBottom: 1px dashed rgba(255, 255, 255, 0.08)`).

### 3. Static Block Flow & Single Global Scrollbar
- Remove all nested flex containers with `flex: 1` or `overflowY: auto` inside the feed.
- Ensure only `HUDOverlay`'s `scrollContainerRef` scrolls the entire document buffer.
- Provide a dedicated `56px` bottom clearance spacer so lines are never clipped against the bottom bezel.
- Keep auto-scroll active so new lines smoothly scroll into view without layout jumping.

### 4. Slimline Control Bar
- Compress the top controls bar (`Mic`, `VU meters`, `Solve`, `Clear`, `Pass-Thru`) to a minimal 28px height, eliminating extra margins so content starts near the top of the HUD.

- Run `pnpm turbo typecheck` to confirm zero type errors.
- Run `pnpm --filter desktop test` to confirm existing test suites pass.
- Verify visually that content density is tripled, no inner scrollbars exist, and code blocks flow naturally like a terminal buffer.
