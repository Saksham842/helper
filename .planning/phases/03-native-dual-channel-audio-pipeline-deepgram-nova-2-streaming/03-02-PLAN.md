# Plan 03-02: Dual-Channel 16kHz Linear16 PCM Multiplexer

## Objective
Build a real-time Web Audio API multiplexer that takes the system loopback audio (Channel 0: Interviewer) and microphone audio (Channel 1: Candidate), merges them into a 2-channel 16,000 Hz Linear16 PCM buffer pipeline, and provides chunked binary audio packets ready for high-speed WebSocket streaming.

## Requirements Covered
- **AUDIO-02**: Candidate microphone stream handled independently on Channel 1.
- **AUDIO-03**: Dual-channel linear16 PCM audio multiplexing for Deepgram Nova-2 streaming.

## Tasks
1. Create `apps/desktop/src/renderer/src/services/audioMultiplexer.ts`:
   - Initialize `AudioContext` with `{ sampleRate: 16000 }`.
   - Create `MediaStreamAudioSourceNode` for loopback stream and microphone stream.
   - Connect both into a `ChannelMergerNode(2)`:
     - `loopbackSource.connect(merger, 0, 0)` -> Left channel (Interviewer).
     - `micSource.connect(merger, 0, 1)` -> Right channel (Candidate).
   - Implement PCM buffer encoding:
     - Convert Float32Array samples (-1.0 to +1.0) into signed 16-bit integers (`Int16Array`, -32768 to 32767).
     - Interleave stereo samples: `[L0, R0, L1, R1, ...]`.
     - Emit binary chunks at 100ms intervals (1600 frames * 2 channels = 6400 bytes per chunk).
   - Provide volume meter metrics (RMS signal level for Interviewer and Candidate) for live HUD visualizer.
2. Add unit tests for PCM interleave conversion and buffer math in `apps/desktop/tests/pcm.test.ts`.

## Verification
- Verify 16kHz PCM chunks are produced with correct byte alignment and stereo interleaving.
- Verify volume meter calculations accurately reflect input amplitude.
