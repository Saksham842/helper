# Plan 03-03: Deepgram Nova-2 WebSocket Client & Real-Time Diarization HUD Feed

## Objective
Implement the Deepgram Nova-2 multi-channel WebSocket client with automatic speaker diarization (Interviewer on Channel 0, Candidate on Channel 1), live interim transcript streaming, auto-reconnect logic, and a real-time transcript feed rendered directly on the floating HUD overlay.

## Requirements Covered
- **AUDIO-03**: Dual-channel linear16 PCM audio streamed via WebSocket to Deepgram Nova-2 with real-time speaker diarization (Interviewer vs Candidate) and auto-reconnect logic.

## Tasks
1. Create `apps/desktop/src/renderer/src/services/deepgramLiveClient.ts`:
   - Connect to Deepgram Nova-2 WebSocket:
     `wss://api.deepgram.com/v1/listen?model=nova-2&language=en-US&smart_format=true&interim_results=true&diarize=true&multichannel=true&encoding=linear16&sample_rate=16000&channels=2`
   - Handle binary PCM streaming from `audioMultiplexer`.
   - Parse JSON response events:
     - Map Channel index 0 -> Speaker: Interviewer (`role: 'interviewer'`).
     - Map Channel index 1 -> Speaker: Candidate (`role: 'candidate'`).
     - Distinguish `is_final: false` (interim live typing preview) vs `is_final: true` (completed utterance).
   - Resilient connection management:
     - Send periodic KeepAlive ping frames to prevent connection timeout during silent pauses.
     - Auto-reconnect with exponential backoff on network dropouts.
2. Build HUD transcript UI in `apps/desktop/src/renderer/src/components/TranscriptFeed.tsx`:
   - Live streaming transcript message bubbles.
   - Distinct visual badges for Interviewer (Purple) and Candidate (Emerald).
   - Audio VU meter bars for both channels showing real-time mic/loopback signal activity.
   - Start / Pause / Stop session controls.
3. Integrate `TranscriptFeed` into `HUDOverlay.tsx`.
4. Validate end-to-end typecheck and build across the monorepo.
