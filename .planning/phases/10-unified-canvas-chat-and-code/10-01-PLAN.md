# Plan 10-01: Live Copilot Seamless Chatbot Canvas

## Objective
Convert `LiveCopilotFeed.tsx` from clunky, fragmented multi-nested card boxes into a unified, high-legibility chatbot canvas inspired by ChatGPT and Claude, allowing candidates to read live interviewer transcriptions and AI guidance seamlessly with peripheral vision during live calls.

## Context & User Feedback
- Current issue: Every conversational turn is wrapped in an outer card plus inner cards (`[Interviewer]` box with cyan border, `[AI Copilot]` box with green border, `[You]` box with purple border).
- User feedback: *"one issue is boxes .... make it compltet canvas dont break into multiple ..... beacuse it is impossible to read in chat copilot section ...... make it like chatbot"*.

## Key Implementation Steps

### 1. Eliminate Multi-Layer Box Framing in `LiveCopilotFeed.tsx`
- Remove outer exchange card wrapper styling (`border: 1px solid rgba(255, 255, 255, 0.08)`, `background: rgba(10, 15, 29, 0.65)`, `boxShadow`, `padding: 6px`).
- Remove inner block borders and boxed card backgrounds for Interviewer, AI Copilot, and Candidate turns.
- Convert the entire exchange timeline into a single, clean vertical chat stream with seamless spacing (`gap: 16px`).

### 2. Style Modern Chat Stream Elements
- **Interviewer Question Turn**:
  - Direct canvas presentation with minimal header: `[Interviewer]` tag or icon in Sky-Blue (`#38bdf8`), timestamp in subtle muted gray (`#64748b`).
  - Question text rendered in clean typography: `fontSize: 12.5px`, `lineHeight: 1.6`, `color: #f8fafc`, `fontWeight: 500`.
  - Subtle left cyan accent bar (`width: 2px`, `background: #38bdf8`) or clean pill to visually anchor the speaker without enclosing it in a box.
- **AI Copilot Guidance Turn**:
  - Flows naturally underneath the question on the same canvas.
  - Header: `[AI Copilot]` in Emerald (`#34d399`), live streaming spinner indicator, and quick-action Copy button with subtle glass styling (`rgba(255, 255, 255, 0.05)`).
  - Markdown content rendered directly onto the canvas with generous line spacing and zero enclosing box borders.
- **Candidate Spoken Speech (`[You]`)**:
  - Appears below the AI suggestion in subtle muted purple (`#c084fc`), indicating what the candidate verbally said, keeping the conversation context continuous.
- **Inter-Exchange Dividers**:
  - Replace thick card boundaries with ultra-faint horizontal hairline dividers (`borderTop: 1px solid rgba(255, 255, 255, 0.05)`, `margin: 12px 0`) to distinguish sequential conversation cycles.

### 3. Maintain Core Functionality
- Preserve dual VU meters, microphone pause/resume controls, clear timeline action, auto-scrolling to bottom, and responsive text wrapping with zero horizontal scrollbars.

## Verification
- Test manual and automated suites: `pnpm --filter desktop test`.
- Run typecheck: `pnpm turbo typecheck`.
- Confirm in renderer that all nested boxes are gone and the chat stream reads as one continuous canvas.
