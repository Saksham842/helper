# Plan 02-02: Screen Protection, Click-Through Engine & Global Shortcuts

## Objective
Implement native screen-share capture protection (`win.setContentProtection(true)` activating Win32 `WDA_EXCLUDEFROMCAPTURE` and macOS `NSWindowSharingNone`), click-through mode (`setIgnoreMouseEvents`), dynamic hover mouse forwarding, and system-wide global shortcuts (`globalShortcut`).

## Requirements Covered
- **STLTH-01**: Electron overlay implements `win.setContentProtection(true)` to guarantee 100% invisibility to screen share software (Zoom, Google Meet, Teams) via Win32 `WDA_EXCLUDEFROMCAPTURE` and macOS `NSWindowSharingNone`.
- **STLTH-02**: Click-through mode (`setIgnoreMouseEvents(true, { forward: true })`) preventing OS focus loss.
- **STLTH-04**: 100% keyboard-driven overlay navigation via Electron `globalShortcut` for toggling visibility, opacity, click-through, and prompt actions.

## Tasks
1. Extend `apps/desktop/src/main/hud.ts`:
   - Invoke `win.setContentProtection(true)` on window initialization.
   - Implement `setClickThrough(enabled: boolean)` using `win.setIgnoreMouseEvents(enabled, { forward: true })`.
   - Implement dynamic hover pass-through: IPC handler `hud:set-ignore-mouse` allowing renderer elements to notify main process when cursor enters/leaves interactive buttons.
   - Implement `setOpacity(level: number)` clamped between 0.1 and 1.0.
   - Implement `toggleVisibility()` using `showInactive()` when becoming visible.
2. Create `apps/desktop/src/main/shortcuts.ts`:
   - Register system global shortcuts using Electron `globalShortcut`:
     - `CommandOrControl+Shift+V`: Toggle HUD visibility.
     - `CommandOrControl+Shift+M`: Toggle click-through mode.
     - `CommandOrControl+Shift+Up`: Increase opacity by +0.1.
     - `CommandOrControl+Shift+Down`: Decrease opacity by -0.1.
     - `CommandOrControl+Shift+H`: Ask AI / Screen Capture hotkey (broadcasts event to renderer).
   - Safe unregistration on `app.on('will-quit', () => globalShortcut.unregisterAll())`.
   - Broadcast state changes to renderer via IPC channel `hud:state-changed`.
3. Update `apps/desktop/src/preload/index.ts`:
   - Expose HUD control methods to `window.electronAPI`:
     - `setClickThrough(enabled: boolean): Promise<void>`
     - `setOpacity(level: number): Promise<void>`
     - `toggleVisibility(): Promise<void>`
     - `setIgnoreMouse(ignore: boolean): void`
     - `getHUDState(): Promise<HUDState>`
     - `onHUDStateChange(callback: (state: HUDState) => void): () => void`
     - `onHotkeyPressed(callback: (action: string) => void): () => void`
4. Update shared types in `packages/shared/src/types/index.ts` with `HUDState` definition.

## Verification
- Run `pnpm run typecheck` across all packages.
- Verify `setContentProtection(true)` is executed during window creation.
- Verify all global shortcuts register cleanly without errors.
