# Plan 02-01: Frameless Transparent HUD Window & OS Stealth Foundation

## Objective
Implement the native Electron stealth window foundation in `apps/desktop/src/main/hud.ts`, configured with frameless transparent glass aesthetics, OS stealth flags (`skipTaskbar: true` on Windows, `app.dock.hide()` on macOS), persistent topmost level (`alwaysOnTop: true` with level `'screen-saver'`), and anti-blur focus neutrality (`focusable: false`, `showInactive()`).

## Requirements Covered
- **STLTH-02**: Overlay window initialized with `focusable: false`, `alwaysOnTop: true` (`level: 'screen-saver'`), preventing OS focus loss and browser `blur`/`visibilitychange` events.
- **STLTH-03**: OS stealth flags: `skipTaskbar: true` on Windows, frameless transparent glass styling, and `app.dock.hide()` on macOS.

## Tasks
1. Create `apps/desktop/src/main/hud.ts`:
   - Define `HUDWindowManager` class.
   - Configure `BrowserWindow` options:
     - `width: 440`, `height: 600`, `x` / `y` positioned at top right of the primary display.
     - `transparent: true`, `frame: false`, `hasShadow: false`, `backgroundColor: '#00000000'`.
     - `skipTaskbar: true` (Windows Taskbar stealth).
     - `focusable: false` (Zero focus-stealing).
     - `alwaysOnTop: true` with level `'screen-saver'`.
     - `setVisibleOnAllWorkspaces(true, { visibleOnFullScreen: true })`.
   - On macOS: call `app.dock?.hide()` on startup.
   - Implement `showHUD()` using `win.showInactive()` instead of `win.show()` to avoid stealing focus from active browser/IDE tabs.
   - Implement `hideHUD()`.
   - Maintain HUD state: `{ isVisible: boolean, opacity: number, isClickThrough: boolean, isContentProtected: boolean }`.
2. Integrate `HUDWindowManager` into `apps/desktop/src/main/index.ts`:
   - Replace standard window instantiation with `HUDWindowManager`.
   - Ensure `copilot://auth` deep links seamlessly route to the HUD window.
3. Validate typecheck and build across the monorepo.

- Confirm window options contain `skipTaskbar: true`, `transparent: true`, `frame: false`, and `focusable: false`.
