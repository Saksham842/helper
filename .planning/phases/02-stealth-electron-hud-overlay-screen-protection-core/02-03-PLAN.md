# Plan 02-03: HUD Floating UI & Screen Protection Verification Harness

## Objective
Design and implement the high-craft floating HUD overlay UI components in `apps/desktop/src/renderer` (translucent dark glass, dynamic mouse pass-through, hotkey indicator pills, opacity slider, stealth indicator badge) and create an automated test harness in `apps/desktop/tests/stealth.spec.ts` validating screen protection (`setContentProtection`), stealth flags (`skipTaskbar`, `focusable: false`), and IPC mechanics.

## Requirements Covered
- **STLTH-01**: Screen-share protection verified against Electron `desktopCapturer` and `isContentProtected()`.
- **STLTH-02**: Overlay window focus neutrality and click-through mode toggling seamlessly in renderer.
- **STLTH-03**: OS stealth UI: frameless transparent glass styling with draggable header.
- **STLTH-04**: Keyboard-driven UI feedback showing real-time shortcut actions.

## Tasks
1. Create HUD floating components in `apps/desktop/src/renderer/src/components/`:
   - `StealthBadge.tsx`: Displays active `Protected (WDA_EXCLUDEFROMCAPTURE)` status with pulsating emerald indicator.
   - `HotkeyCheatsheet.tsx`: Displays compact shortcut badges (`Ctrl+Shift+V` Hide/Show, `Ctrl+Shift+M` Click-Through, `Ctrl+Shift+↑/↓` Opacity).
   - `HUDOverlay.tsx`: Main floating HUD window container with:
     - Draggable header bar (`-webkit-app-region: drag`) with custom window action controls.
     - Mouse enter/leave handlers communicating with `electronAPI.setIgnoreMouse` for dynamic transparency pass-through.
     - Live HUD state synchronization (opacity, click-through, content protection).
     - Minimizable / collapsible view mode for zero distraction during coding interviews.
2. Update `apps/desktop/src/renderer/src/App.tsx`:
   - Integrate `HUDOverlay` as the primary interface.
   - Combine with `AuthStatus` so user credentials from deep linking display cleanly.
3. Create automated test harness `apps/desktop/tests/stealth.spec.ts`:
   - Verify `BrowserWindow` creation properties: `frame === false`, `transparent === true`, `skipTaskbar === true`, `focusable === false`.
   - Verify `win.isContentProtected() === true` after window initialization.
   - Verify `setIgnoreMouseEvents` toggling does not throw and accurately reflects in `getHUDState()`.
   - Verify `desktopCapturer` execution with content protection active.
4. Execute `turbo run typecheck` and `turbo run build` across all workspace packages to ensure end-to-end type safety and clean bundling.
