## Phases & Deliverables

### Phase 1: Monorepo Scaffold, Database Schema, Auth & Desktop Deep-Linking
- Turborepo monorepo with pnpm workspaces supporting `apps/web`, `apps/desktop`, and `packages/shared`.
- Strict TypeScript configuration (`tsc --noEmit`), shared Zod schemas, and synchronized types.
- Supabase SSR authentication client with cookies, Row Level Security (RLS) on PostgreSQL tables.
- Desktop deep-linking protocol (`copilot://auth?token=...`) with single-instance lock handler on Windows and macOS.

### Phase 2: Stealth Electron HUD Overlay & Screen Protection Core
- Frameless, transparent Electron overlay window with anti-blur OS focus preservation (`showInactive()`, `focusable: false`).
- Hardware screen capture invisibility via Win32 `WDA_EXCLUDEFROMCAPTURE` and macOS `NSWindowSharingNone` (`win.setContentProtection(true)`).
- Click-through transparent pass mode (`setIgnoreMouseEvents(true, { forward: true })`).
- Global hotkey listener (`Ctrl+Shift+V`, `Ctrl+Shift+M`, `Ctrl+Shift+Up/Down`, `Ctrl+Shift+H`).

### Phase 3: Native Dual-Channel Audio Pipeline & Live Streaming
- WASAPI loopback audio capture for caller/interviewer audio without browser recording banners.
- Microphone capture for candidate speech on isolated channel.
- Dual-channel 16-bit 16kHz linear PCM interleaving multiplexer and real-time visual VU meter.

### Phase 4: Real-Time AI Answer Engine & Silent Vision Problem Solver
- Heuristic question detector identifying technical queries and filtering conversational fillers.
- Context-aware prompt engine injecting candidate resume, role, and custom instructions.
- Sub-second streaming answer generation with Claude 3.5 / 4.
- Silent screen capture (`desktopCapturer.getSources`) and Claude Vision solver for coding challenges.

### Phase 5: 100% Free Architecture — Resume Vault & Local Whisper STT
- Document & Resume Vault supporting PDF and DOCX uploads with server-side text extraction (`pdf-parse`, `mammoth`).
- Free local offline Whisper STT engine via `@huggingface/transformers` (`onnx-community/whisper-base.en` ONNX) with VAD diarization.
- Free browser-native Voice AI Mock Interviewer simulator using Web Speech API and post-call analytics.
- Categorized Technical Question Bank with track filters and difficulty ratings.

### Phase 6: Hardening, Packaging, Stealth Verification & Automated Test Suites
- Comprehensive REA security audit confirming zero secret key leakage and strict IPC boundaries.
- 5 desktop CommonJS test suites (21 checks) and 4 web Vitest test suites (33 tests) passing with 0 failures.
- Playwright E2E smoke tests validating web dashboard flows and health endpoint.
- Production installer packaging (`SystemAudioHelper.exe` NSIS installer and macOS `.dmg`) with Electron fuse hardening (`RunAsNode=false`, `EnableNodeCliInspectArguments=false`, `OnlyLoadAppFromAsar=true`).
- Zero-click Vercel deployment configuration (`vercel.json`, `/api/health`).
- Root `start-copilot.bat` convenience launcher.
